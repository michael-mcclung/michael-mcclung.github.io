Folio

Personal income and expense ledger. Sign-in has staff and admin roles, and each person sees only their own book. Charts cover income, expenses, and spending by category. Export the filtered rows to CSV or Excel, or save a monthly PDF. The interface is in English and Vietnamese. The suite has 14 tests. It is not deployed.

Blockchain Exchange

A Python and Flask blockchain stock exchange with wallets, signed stock transfers, proof-of-work mining, and a chain view. It records a ticker and a quantity on a toy chain, does not connect to a market, and is not for real funds. A webcam-driven, face-controlled virtual mouse runs on the desktop. It started as a Texas Tech Software Engineering I team project. Maktm wrote the 2019 Flask exchange. The revival runs on Python 3.11 and newer, with pytest, GitHub Actions, and an in-browser demo.
